## 안녕하세요, 예범입니다.

게임의 규칙을 설계하고, 코드로 상호작용을 만드는 크리에이티브 개발자입니다.<br>
Unity 게임플레이 시스템부터 VR 경험, 인터랙티브 웹까지 **기획의 의도를 실제로 작동하는 경험으로 구현하는 과정**을 좋아합니다.

```text
DESIGN THE INTERACTION  →  BUILD THE SYSTEM  →  REFINE THE EXPERIENCE
```

- VR 인터랙션을 사용자의 행동 흐름과 자연스럽게 연결하기

## How I Work

1. **Why부터 정의합니다.** 기능보다 먼저 사용자가 어떤 상황에서 무엇을 경험해야 하는지 정리합니다.
2. **구조를 나눕니다.** 입력, 상태, 생성, 충돌과 UI의 책임을 분리해 수정 가능한 시스템을 만듭니다.
3. **직접 검증합니다.** 플레이와 관찰을 반복하며 기획의 의도가 실제 경험에서도 전달되는지 확인합니다.
